1Antes de empezar

Hermes corre nativo en Windows. La instalación es por usuario: no pide administrador y deja todo en %LOCALAPPDATA%\hermes.

NecesitasWindows 10 u 11 · PowerShell · conexión a internet
No necesitasWSL · Docker · permisos de admin · Python instalado
Si el PC tiene proxy corporativo, defínelo antes de instalar en la misma ventana de PowerShell:
$env:HTTPS_PROXY="http://tu-proxy:puerto"

2Instalación

Paso 1 · Abrir PowerShell

Menú Inicio → escribe PowerShell → clic derecho → Ejecutar como usuario normal (no hace falta admin).

Paso 2 · Permitir scripts solo en esta ventana

Muchos PC de empresa bloquean los scripts. Esto lo habilita únicamente para la sesión actual, sin tocar la configuración del equipo:

PowerShell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Paso 3 · Instalar

PowerShell
irm https://hermes-agent.nousresearch.com/install.ps1 | iex

Tarda unos minutos: baja el código, prepara Python y deja el comando hermes disponible.

Paso 4 · Verificar

Cierra esa ventana, abre una nueva y comprueba:

PowerShell
hermes --version
hermes doctor
Bien: si hermes doctor no marca errores rojos, quedó listo. Si algo falla, el mismo comando dice qué falta.

3Configuración del modelo

El bot necesita un proveedor de IA. Es lo único que requiere una clave.

PowerShell
hermes setup

El asistente te guía: eliges proveedor, pegas la API key y quedas con un modelo por defecto. Después puedes cambiarlo cuando quieras con:

PowerShell
hermes model
hermes config edit
Regla práctica: el perfil que redacta o investiga usa el modelo bueno. Los perfiles que solo revisan o clasifican pueden usar uno más barato y ahorras bastante.

4Los bots: qué es un perfil

Cada bot es un perfil: una instancia independiente con su propio modelo, su memoria, sus skills, sus credenciales y su historial. No se mezclan entre sí.

  • Perfil = quién es el bot. Vive en %LOCALAPPDATA%\hermes\profiles\<nombre>\
  • Rol = la descripción que le das. Es lo que lee el gerente para saber a quién mandarle cada pega.
  • Tarjeta = la tarea concreta, con instrucciones, asignada a un perfil.
PowerShell
hermes profile list
hermes profile show catalogo

5Organigrama propuesto para Mallu

Seis perfiles. El gerente no ejecuta: solo reparte. El revisor es el que evita que algo mal escrito llegue a la tienda.

PerfilRolQué hace
gerenteOrquestadorDescompone el pedido en tarjetas, las asigna y controla el avance. No escribe ni publica nada.
catalogoFichas de productoTítulo SEO, descripción en español, categoría, tags y precio sugerido para WooCommerce.
preciosCompetenciaVigila precios de otras tiendas chilenas, detecta bajas y propone ajustes de margen.
contenidoMarketingPosts de novedades, anime, Instagram y correo Mailchimp con las plantillas de la tienda.
soporteAtenciónResponde consultas de pedidos y envíos (Starken, Chilexpress, BlueExpress) y deriva los casos raros.
revisorControl de calidadLee lo que produjeron los otros y devuelve correcciones antes de publicar.
Límite importante: ningún perfil publica en la tienda sin que el revisor haya pasado. Automatizar la publicación sin control es la forma más rápida de llenar el catálogo de errores.

6Crear todo de una vez

Copia este bloque completo en PowerShell. Crea los seis perfiles y les asigna el rol. --clone copia tu configuración y tu modelo a cada uno, así no tienes que configurar la clave seis veces.

PowerShell · bloque completo
hermes profile create gerente --clone
hermes profile create catalogo --clone
hermes profile create precios --clone
hermes profile create contenido --clone
hermes profile create soporte --clone
hermes profile create revisor --clone

hermes profile describe gerente "Orquesta: descompone pedidos en tarjetas, asigna y controla. No ejecuta tareas."
hermes profile describe catalogo "Fichas de producto WooCommerce: titulo SEO, descripcion en espanol, categoria, tags y precio sugerido."
hermes profile describe precios "Vigila precios de competencia en tiendas chilenas y propone ajustes de margen."
hermes profile describe contenido "Posts de novedades, anime, Instagram y correo Mailchimp con las plantillas de Mallu."
hermes profile describe soporte "Responde consultas de pedidos y envios. Deriva los casos que requieren decision humana."
hermes profile describe revisor "Control de calidad: corrige antes de publicar. No produce contenido propio."
Las descripciones van sin tildes a propósito: PowerShell antiguo puede estropear los acentos al pegar. El resto del sistema funciona igual.

Verifica que quedaron:

PowerShell
hermes profile list

7El tablero: tarjetas y despacho

El flujo es simple: creas una tarjeta con instrucciones, la asignas a un perfil, y el despachador despierta a ese bot para que la ejecute.

Crear una tarjeta

PowerShell
hermes kanban create "Fichas de 10 Funkos nuevos" --assignee catalogo --body "Genera titulo, descripcion, categoria y tags para estos 10 productos. Espanol neutro, sin inventar stock ni medidas. Devuelve una tabla."

Ver el tablero

PowerShell
hermes kanban ls
hermes kanban show <id>
hermes kanban stats

Poner a trabajar a los bots

PowerShell · deja esta ventana abierta
hermes kanban daemon

Si prefieres una pasada y cerrar:

PowerShell
hermes kanban dispatch

Encadenar bots

Una tarjeta puede esperar a otra. El revisor no parte hasta que el catálogo termine:

PowerShell
hermes kanban create "Revisar las 10 fichas" --assignee revisor --parent <id_de_la_tarjeta_anterior> --body "Revisa coherencia, ortografia y que no haya datos inventados. Devuelve lista de correcciones."

La oficina, en el navegador

PowerShell
hermes dashboard

Abre http://localhost:9119. Ahí ves cada bot, en qué tarjeta está trabajando y cuánto lleva gastado.

8Carpetas y espacios de trabajo

Dos cosas distintas. El perfil tiene siempre su carpeta propia. La tarea se ejecuta en el espacio que tú elijas al crearla:

EspacioQué significaCuándo usarlo
scratchCarpeta temporal aislada (por defecto)Investigación, redacción, análisis
dir:C:\rutaUna carpeta real tuyaLeer exports de productos, planillas, fotos
worktreeCopia con rama de gitTocar código sin romper lo que funciona
PowerShell
hermes kanban create "Ordenar el export de productos" --assignee catalogo --workspace "dir:C:\Mallu\productos" --body "Lee el CSV de esta carpeta y devuelve la tabla normalizada."

9Las primeras tareas

Para arrancar sin complicarte, en este orden:

  1. catalogo · "Fichas de 10 productos" — mide calidad y tiempo antes de escalar a 100.
  2. revisor · "Revisar esas fichas" — encadenada a la anterior.
  3. precios · "Comparar precios de estos 20 productos en 3 tiendas chilenas".
  4. contenido · "Post de novedades de la semana" con las plantillas que ya usas.
  5. soporte · "Clasificar los correos de la última semana" — solo clasificar, no responder todavía.
Regla de oro: la primera tarjeta de cualquier bot nuevo es mapear y documentar, no producir. Así queda una skill escrita y la segunda vez trabaja diez veces mejor.

10Costos y control

PowerShell
hermes insights --days 7
hermes kanban stats
hermes kanban ls
  • Modelo por bot: los perfiles de revisión pueden usar un modelo barato. Se cambia con hermes -p revisor model.
  • Freno de mano: si un bot se queda pegado, hermes kanban reclaim <id> corta el worker al instante.
  • Reasignar: hermes kanban reassign <id> otro-perfil --reclaim si el rol no era el correcto.
  • Límite de tiempo: al crear la tarjeta puedes fijar --max-runtime para que no se eternice.

11Problemas típicos

SíntomaCausa y solución
“no se puede cargar el archivo … por la directiva de ejecución”Vuelve a correr Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass en esa ventana y repite.
El instalador no conectaProxy corporativo. Define $env:HTTPS_PROXY antes de instalar y revisa que el firewall permita salir a la API del proveedor.
Error 400 “No models provided”El config.yaml quedó guardado con BOM. Guárdalo como UTF-8 sin BOM.
hermes no se reconoce como comandoCierra y abre PowerShell de nuevo para que tome el PATH.
El dashboard no abreVerifica que el proceso siga vivo y entra a http://localhost:9119 exacto (no https).
Un bot no toma la tarjetaMira que el despachador esté corriendo (hermes kanban daemon) y que el assignee exista en hermes profile list.

12Opción A: bot propio en el PC del trabajo

En lugar de que un computador controle al otro, el PC del trabajo corre su propio agente y tú lo manejas por Telegram desde cualquier lado. Ese bot ve los archivos y la red de la empresa; el de la casa sigue con la tienda.

Son dos agentes independientes: no comparten memoria, skills ni historial. Cada uno vive en su máquina y se configura aparte.

Paso 1 · Crear el bot en Telegram

  1. Abre Telegram y busca @BotFather
  2. Escribe /newbot, ponle nombre y usuario (por ejemplo MalluTrabajoBot)
  3. Te devuelve un token del tipo 123456:ABC-DEF.... Guárdalo: es la llave del bot
  4. Busca @userinfobot, mándale cualquier mensaje y anota tu ID numérico

Paso 2 · Conectar el bot en el PC del trabajo

PowerShell · en el PC del trabajo
hermes gateway setup

Elige Telegram, pega el token y, cuando pregunte por usuarios autorizados, escribe tu ID numérico.

El error más común: si en esa pregunta eliges Skip, el bot se conecta pero rechaza todos los mensajes, incluidos los tuyos. Parece muerto y no lo está. Siempre pon tu ID o elige modo de emparejamiento.

Paso 3 · Dejarlo corriendo

PowerShell · en el PC del trabajo
hermes gateway install
hermes gateway start
hermes gateway status

En Windows el servicio puede no instalarse igual que en Linux. Si install no toma, déjalo con hermes gateway run en una ventana abierta, o crea una tarea en el Programador de tareas que ejecute ese comando al iniciar sesión.

Paso 4 · Probarlo

Escribe /sethome al bot para fijar ese chat como canal de avisos. Después pídele algo que solo pueda hacer allá:

Mensaje de prueba
Revisa la carpeta Descargas y dime los 5 archivos mas pesados

Si responde con datos reales, quedó operativo y con acceso a esa máquina.

Qué gana y qué no: gana acceso a los archivos y a la red de la empresa, y lo manejas desde el teléfono. No hereda tus skills ni la memoria del bot de la casa: si quieres que sepa de la tienda, hay que dárselo allá.
Si el firewall lo bloquea: el bot necesita salida a api.telegram.org. Si la empresa lo filtra, va a conectar y desconectarse en bucle. Se comprueba desde PowerShell con Test-NetConnection api.telegram.org -Port 443.
Seguridad: el token es la llave del bot. No lo pegues en chats ni documentos compartidos. Si se filtra, en @BotFather usa /revoke y genera otro.

Checklist final

  • Instalado y hermes doctor sin errores
  • Modelo configurado con hermes setup
  • Seis perfiles creados y descritos
  • Primera tarjeta de catálogo ejecutada y revisada
  • Dashboard abierto en localhost:9119
  • Modelo barato asignado a revisor y soporte
  • Bot del trabajo creado en @BotFather, con token y tu ID autorizado
